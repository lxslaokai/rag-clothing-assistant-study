## 二、RAG 与模型训练

### RAG-01：上传资料为什么不需要重新训练聊天模型？

**题目**：为什么这个项目上传了尺码文件之后，不需要重新训练 qwen-plus，也有可能回答文件中的问题？

**你的答案**：因为模型会根据我们提供的外部资料库进行回答。

**判断**：正确，抓住了使用外部资料的核心。还需明确资料如何提供给模型。

**参考答案**：程序先从知识库检索相关资料，再把检索片段与用户问题一起放进提示词，发送给聊天模型。模型根据这次输入组织回答，因此不需要为上传文件而更新聊天模型的参数。

**解析**：不是聊天模型自动连接并读完整个资料库，而是项目中的检索流程负责找资料并把选中的片段交给它。可以理解为先找出相关书页，再交给参加开卷考试的人。

**题后总结**：

- 上传和向量化资料，不等于训练聊天模型。
- 检索负责找资料，生成负责依据输入组织回答。
- 本项目没有通过该上传过程修改 qwen-plus 的内部参数。
- 回答正确还不够，应检查实际检索片段，才能核对证据来源。

## 三、向量化与检索

### 核心笔记：怎样找到相关资料？

1. 文档先被切成片段。
2. 嵌入模型（embedding model）把片段转换为数字向量；向量可理解为用于比较文本的数字表示，而不是人工指定的关键词标签。
3. 用户问题也由同一个嵌入模型转换为向量，以便进行可比较的相似度计算。
4. 向量库按相似程度返回候选片段；语义接近的文本通常更容易被召回，但不保证一定找对。
5. 选出的片段与问题一起交给聊天模型生成回答。

本项目的嵌入模型是 text-embedding-v4，聊天模型是 qwen-plus。
当前检索配置返回最相近的最多 2 条片段，并非已经设置了相似度合格阈值。
即使没有真正相关的资料，也可能返回候选片段，因此后续需要检查检索结果和无答案时的行为。

### RAG-02：识别相关片段

**题目**：用户问“身高 182 cm，XXL 上衣是否在推荐身高范围内？”候选片段 A 是“XXL 上衣适合身高 180–185 cm”，片段 B 是“深色衣物建议单独洗涤”。程序应优先找到哪一段？请说明理由。

**你的答案**：A，因为有相关的文字，XXL 上衣，身高也是在范围内，属于相近语义。

**判断**：选择正确，理解了语义相关。需要把“检索相关资料”和“根据资料作判断”区分开。

**参考答案**：应优先检索 A，因为它直接提供 XXL 上衣推荐身高范围，是回答该问题所需的证据；B 讨论洗涤，与问题无关。

**解析**：文字重合可以是线索，但向量检索并不是仅凭相同关键词找资料，也不要求资料支持肯定结论。182 cm 是否落在 180–185 cm 范围内，是取到资料之后需要作出的判断，不是判断该片段是否值得检索的必要条件。

**题后总结**：

- 检索找的是与问题相关、能提供证据的资料，不是只找支持“是”的资料。
- 在本项目流程中，检索器返回候选片段，聊天模型再根据片段组织回答。
- 语义相似并不保证精确数值判断正确，仍需检查回答是否忠于资料。

### RAG-03：相关资料能否支持否定回答？

**题目**：假设资料改为“XXL 上衣推荐身高 190–195 cm”，用户仍问“我身高 182 cm，是否在 XXL 上衣的推荐身高范围内？”请用一句话说明这段资料是否仍值得检索，以及依据它应给出什么结论。

**你的答案**：值得，因为也是关于 XXL 上衣推荐的。结论是否。

**判断**：正确。最后一句结合上下文理解为“结论是‘否’”。

**参考答案**：值得检索，因为它直接提供 XXL 上衣推荐身高范围；依据这段资料，182 cm 不在 190–195 cm 范围内。

**解析**：一段资料可以与问题相关，同时支持否定答案。不能因为其数值不符合用户条件就认为检索错了。这里只判断是否落在给定身高范围，不据此推出衣服一定不能穿。

**题后总结**：检索相关性和最终判断不同；找到证据后，应依据资料中的具体条件回答，而不是只匹配关键词。

## 九、读代码：将检索结果整理为提示词资料

### RAG-09：`format_document` 的空列表判断

**实际代码位置**：`rag.py` 的 `_get_chain` 方法内部。

```python
def format_document(docs: list[Document]):
    if not docs:
        return "无相关参考资料"
    formatted_str = ""
    for doc in docs:
        formatted_str += f"文档片段:{doc.page_content}\n文档元数据:{doc.metadata}\n\n"
    return formatted_str
```

**解析**：`docs` 是已经检索到的文档对象列表；`list[Document]` 是输入类型提示，不会自动检索资料。`if not docs` 判断列表是否为空。`formatted_str` 从空字符串开始，循环取出每个文档，把正文和元数据拼接进去，最后返回整理后的字符串。`+=` 表示把右侧文字追加到原字符串；f-string 填入属性值；`\n` 在结果字符串中表示换行。该函数的输出随后作为 `context` 传入提示词模板，不直接调用模型。

**题目**：检索器返回了两段服装资料，但两段都没有实时库存信息。此时 `if not docs` 会成立并返回“无相关参考资料”吗？请说明原因。
